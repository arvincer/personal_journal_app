# 在 Windows 上免费侧载到 iPhone

本项目不依赖 App Store。GitHub Actions 会生成 `personal-journal-unsigned.ipa`，它不含证书、Apple 账号或签名，不能直接点开安装。你需要在 Windows 上用可信的本地侧载工具，通过自己的免费 Apple 账号重新签名并安装。

## 第一次安装

1. 在 GitHub 项目的 Actions 页面运行 **iOS unsigned build**，完成后下载 `personal-journal-unsigned-ios` 产物并解压得到 IPA。
2. 在 iPhone 的“设置 → 隐私与安全性 → 开发者模式”中启用开发者模式，并按系统提示重启。
3. 在 Windows 安装你选择的本地侧载工具。按照该工具的官方说明连接 iPhone；如工具要求 Apple 的设备驱动组件，也只从 Apple 或该工具的官方说明所指向的来源安装。
4. 建议专门注册一个只用于侧载的 Apple 账号。不要把主账号密码交给不可信服务，也不要把账号、密码或签名证书上传到本项目或 GitHub Actions。
5. 选择下载的 IPA 完成签名和安装。应用标识必须始终保持 `app.personaljournal.mobile`。
6. 首次打开后创建一条测试日志，关闭并重新打开应用，确认数据仍在。

## 每周刷新

免费账号签名通常需要在七天内刷新。应用中的“设置 → 免费侧载提醒”只是根据你手动确认的刷新日期估算剩余天数，无法读取 Apple 的真实签名状态。

建议每周按下面顺序操作：

1. 在应用设置页点“创建完整备份”，把 ZIP 保存到电脑或其他安全位置。
2. 使用同一个侧载工具、同一个 Apple 账号和相同 Bundle ID 刷新安装。
3. 刷新成功后直接打开原应用，不要先卸载旧版本。
4. 检查已有用户、日志、图片和视频是否正常。
5. 回到设置页点“我刚刚完成刷新”，重新开始七天估算。

## 重要提醒

- 不要为了更新而卸载应用；iOS 会连同应用私有目录中的日志和媒体一起删除。
- 如果工具提示要安装成另一个应用，先停止并检查 Bundle ID，避免产生两份互不共享数据的应用。
- 每次刷新前都创建完整备份。若数据异常，使用设置页的“从完整备份恢复”，先查看预览再确认合并。
- CI 产物是无签名包；签名只应在你的 Windows 电脑上完成。
