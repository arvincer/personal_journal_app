# 发布检查清单

## 自动检查

- [ ] `dart format --output=none --set-exit-if-changed lib test integration_test`
- [ ] `flutter analyze`
- [ ] `flutter test`
- [ ] macOS CI 的 iOS 模拟器集成测试通过
- [ ] `flutter build ios --release --no-codesign` 通过
- [ ] CI 产物中存在 `personal-journal-unsigned.ipa`，且仓库/日志没有 Apple 密码、证书或签名密钥
- [ ] iOS 与 Android 标识均为 `app.personaljournal.mobile`

## 真机核心流程

- [ ] iPhone 系统听写可向常驻输入框输入文字，应用不请求麦克风权限、不生成录音文件
- [ ] 一次选择多张图片后均可预览、发布、重启后显示
- [ ] 选择视频后可看到缩略图和时长，发布、重启后可读取
- [ ] 导入后从系统相册删除原图片/视频，日志内副本仍可读取
- [ ] 创建“我的日志”和“孩子”，切换后草稿、时间线、日历和导出范围互相隔离
- [ ] 强制结束应用并重开，未发布草稿可以恢复
- [ ] 编辑已发布日志不会改变原创建时间；删除前有确认提示
- [ ] 日历跨月、跨年、空月份和每日条数显示正确

## 导出与 Windows

- [ ] 分析包可以分享到微信文件传输助手
- [ ] 分析包可以保存到 iOS“文件”应用
- [ ] Windows 能正常解压 ZIP，中文文件内容无乱码
- [ ] 每日 Markdown 中图片链接和视频缩略图链接可解析
- [ ] 不包含原视频时仍有视频缩略图、说明和时长；开启后包含原视频
- [ ] 将分析包交给选定 AI 工具，能按用户和日期读取内容

## 备份与恢复

- [ ] 完整备份包含 `backup.sqlite`、全部引用媒体、`manifest.json` 和 `checksums.json`
- [ ] 在新安装/空数据库上恢复后，用户、日志、图片和视频数量及内容一致
- [ ] 同一备份再次恢复不会产生重复数据
- [ ] 坏校验和、缺失媒体和恶意路径 ZIP 被拒绝，且不留下半成品数据
- [ ] 低存储空间下导入、导出和备份会显示失败，不会把半成品当成功文件

## 离线与免费侧载

- [ ] 飞行模式下记录、编辑、日历、导出、备份与恢复仍可用（系统分享目标本身可能需要网络）
- [ ] 设置页侧载剩余天数明确标注为基于用户确认日期的估算
- [ ] 剩余两天或更少时显示备份/刷新提醒
- [ ] 刷新前完成完整备份
- [ ] 使用同一 Apple 账号和 Bundle ID 刷新，不卸载旧应用
- [ ] 刷新后检查原有日志与媒体，再点“我刚刚完成刷新”
